# Keystatic 功能总成

站长在原 Keystatic → **功能总成**管理本站支持的功能、Manager入口、语言及视觉开放位置；保存仍使用原生 GitHub CMS。本站采用严格 schemaVersion:2、scope:features，文件为 src/data/site-config.json；只接管开关和目标语言，首页/设计继续本站原实现。版本字段不是母版版本号，不代表整站升级。

产品、所有文章、翻译、站点视觉、媒体、发布各有独立控制；评价和管理员分析沿用原业务选择。详细文案、图片、AI导航参数等保留在原设置页，对应总成关闭时入口锁定。原文件重复控制值保留但不再生效；新开关只从总成修改。本站未安装自动文章执行器，不提供虚假启用入口；下载只提供现有关闭/留资保护方式。验证码选择仍要求原匹配配置和服务端校验，失败不会降级。

Manager只维护允许的内容，不能改开关或凭据。后台15秒或重新聚焦复核当前已保存设置，未保存编辑保留；重新打开后可继续用原资料。关闭媒体不撤下已有图片，关闭内容管理不删除或隐藏公开产品/文章；关闭翻译不阻止已上线译文按正式内容管理。发布关闭保留已受理发布的状态查询。服务器和最终Git写回同时校验，未知/无效设置拒绝操作并给出重试提示。

保存设置不等于公开生效：公开语言、下载、评价及AI导航等仍按原“发布网站更新”构建上线；site-config保存排除即时自动发布。原生Keystatic/GitHub权限与Manager会话各自保留，隐藏入口不能代替GitHub仓库ACL。

检查：npm run test:features；npm run test:features:ui；npm run test:manager；npm run check:template；npm run build。测试只用隔离资料；实际结果和来源见本站能力登记及PROJECT-PROGRESS。

回滚需审查后来CMS，将本批配置、解析、UI、服务端和工作流过滤协调范围化恢复；不只删除解析器或单个键。保留内容、草稿、D1/R2和已发生的外部任务。客户初始母版来源保持，后续仅记录本CAP采纳；不影响其它客户。
